Comment rejoindre le serveur

Suis ce guide étape par étape pour installer le modpack et te connecter à BMC4.

1

Installer le Launcher CurseForge

Si tu n'as pas encore CurseForge, télécharge-le depuis le site officiel . Installe-le et connecte-toi avec ton compte (création gratuite si besoin).

2

Télécharger le modpack Better MC

Rends-toi sur la page du modpack Better MC [FORGE] - BMC4 et clique sur "Install" ou télécharge la version v36+.

Assure-toi de sélectionner la version Forge pour Minecraft 1.20.1
3

Installer et lancer le modpack

Une fois téléchargé, CurseForge va automatiquement installer tous les mods nécessaires. Lance le modpack en cliquant sur "Play" dans l'interface CurseForge.

  • Attends que tous les mods se chargent (première fois = long)
  • Minecraft va se lancer automatiquement
  • Si erreur Java : vérifie que tu as Java 17+ installé
4

Se connecter au serveur BMC4

Dans Minecraft, va dans "Multijoueur" puis "Ajouter un serveur".

Nom du serveur : BMC4 Server (au choix)
Adresse IP :
bmc4.minesr.com

Clique sur "Terminé" puis rejoins le serveur.

Whitelist Active : Si tu n'es pas autorisé, contacte un admin sur Discord pour être ajouté à la liste blanche.
5

Installer Simple Voice Chat (optionnel)

Le mod Simple Voice Chat n'est pas inclus par défaut. Pour discuter avec tes amis en audio spatial, tu dois l'installer manuellement.

a) Télécharger le mod

Rends-toi sur CurseForge - Simple Voice Chat et télécharge la version compatible Forge 1.20.1.

b) Ajouter le mod à l'instance
  • Ouvre CurseForge et fais clic droit sur l'instance BMC4
  • Sélectionne "Open Folder" ou "Ouvrir le dossier"
  • Place le fichier .jar téléchargé dans le dossier "mods"
  • Redémarre Minecraft
c) Configurer le Voice Chat

Une fois en jeu, appuie sur la touche V pour ouvrir les paramètres audio.

  • Sélectionne ton micro dans les paramètres
  • Ajuste le volume de sortie selon tes préférences
  • Appuie sur Caps Lock pour parler (par défaut)
Tous les joueurs doivent avoir le mod installé pour pouvoir communiquer entre eux.
